# Troubleshooting

## The game stops at the mod loader

Use the Eternal Voyage client pack and the Forge version provided for the server. If the loader reports a missing mod or incompatible version, check that your launcher is using the current Eternal Voyage profile.

## My Log Pose shows no island

The Eternal Voyage server starts characters in the Blues. If the Log Pose still shows no island after you make landfall, open the island chart again while on land. Check that you are using the [One Piece World Log Pose](../voyage/navigation.md#log-pose-and-atlas).

## A chapter or quest is locked

- Check its prerequisite quests and whether your current race, faction, fighting style, or profession matches the chapter.
- For **The Log Pose Remembers**, collect the island’s local mission rewards in the Log Pose. Check the FTB chapter after the Log Pose records the island as complete.
- For a world event, confirm that it has started. For a group objective, check both the personal and server counters.

## The rules differ from the guide

Check [Pack rules](pack-changes.md) for the rule and its related guide. If your results still differ, tell the server team what you were trying, where you were, and what the game showed.
